# 4x-speed-mp4-player

チケット起点AI実装の試行。
実機確認はDebian/arm64。mac,windowsは将来確認。

MP4 動画を 1.00x〜4.00x の範囲で 0.25 刻みの速度を指定して再生する、シンプルなデスクトップ用プレイヤーです。操作はマウスだけで行います。

- 状態: 実装前（要件定義のみ）
- 要件定義書: [docs/requirements.json](docs/requirements.json)
- 作者: T.ishii

> 本 README は要件定義書の要約です。記述に食い違いがある場合は、[要件定義書](docs/requirements.json) を優先します。

## 機能

- MP4 ファイルの読込
  - ウィンドウのどこへのドロップ、または「Choose file」ボタンで指定
  - 拡張子は小文字の `.mp4` のみ受け付けます（`.m4v`、`.mov`、大文字の `.MP4` は拒否します）
  - ドラッグ中はドロップ先のオーバーレイを表示します（推奨）
  - 複数ファイルをまとめてドロップした場合は、先頭の 1 つだけを再生します
- 再生／一時停止、シーク（0.1 秒刻み）、時間表示（現在位置 / 総時間）
- 映像のクリックで再生／一時停止（推奨）
- 再生速度の変更（1.00x〜4.00x、0.25 刻み、「Slower」「Faster」ボタン）。速度を変えても音程は変わりません。
- 音量の変更（0%〜125%、既定 0%、スライダーで操作）
- 表示サイズのマウス変更（映像右下のハンドルをドラッグ。縦横比を維持）
- ループ再生（既定オフ、「Loop」ボタン）
- ファイルの差し替え（速度・音量・表示サイズ・ループの設定を維持。再生位置は先頭に戻ります）
- エラーや通知のメッセージ表示（英語のみ）
- 操作できない部品は薄い色で表示します

## 対象外

- 動画の編集、切り出し、保存
- ネットワーク経由の動画（URL 再生、ストリーミング）
- 字幕、プレイリスト
- タッチ操作（デスクトップ版のため）
- 対応コーデックの追加（将来検討）
- 設定と再生位置の保存（設定は維持しますが、再生位置は起動するたびに既定値に戻ります）
- 複数ファイルの同時再生（先頭の 1 つだけを再生）
- 1.00x 未満（スロー再生）

## 操作・制約

- 操作はマウスのみです。アプリ独自のキーボード操作は持ちません。
- 画面に表示する文字はすべて英語です。
- 対応コーデック（H.264、HEVC など）は、アプリに含まれる Chromium（Electron）の既定に従います。アプリ側では判定・変換しません。
- ウィンドウは 1 つです。二重に起動した場合は、既存のウィンドウを前面に出します。

## 技術構成

- Electron（デスクトップアプリ）
- React 19 + TypeScript
- Vite（ビルド・開発サーバー）
- 再生は HTML5 `<video>`、音量は Web Audio の GainNode
- 配布は electron-builder

## 実行方法

### 必要なもの

- Node.js（LTS 版）と npm
- E2E テストを実行する場合のみ: ffmpeg（libx264 と AAC のエンコーダーを含むもの）

### 手順

```bash
npm install
```

アプリを起動します（ビルドしてから Electron で開きます）。

```bash
npm start
```

テストを実行します。

```bash
npm test          # 単体・コンポーネントテスト（Vitest）
npm run test:e2e  # E2E テスト（Playwright）。初回は ffmpeg で e2e/fixtures/ にテスト用 MP4 を生成します
```

配布用パッケージを `release/` に作成します。

```bash
npm run dist
```

### その他

- `npm run dev` は Vite の開発サーバーだけを起動します。ブラウザで画面を確認するためのものです。ウィンドウや単一起動などの Electron 側の動作は確認できません。Electron で確認するには `npm start` を使います。
- 型チェックとビルドは `npm run build` で行えます。

## 配布対象

| OS | 形式 | アーキテクチャ |
|---|---|---|
| Linux | AppImage | x64、arm64 |
| macOS | dmg | arm64（M1 以降） |
| Windows | NSIS | x64 |

コード署名はしていません。macOS と Windows では初回起動時に警告が出ます。配布物には OS 標準の許可手順の案内を含めます。Linux（AppImage）は実行権限の付与手順を含めます。
