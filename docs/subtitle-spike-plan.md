# 字幕対応（#18）試行の計画

- ブランチ: `feature/subtitle-spike`（`docs/readme-run-instructions` の HEAD `15d626b` から分岐）
- 位置づけ: **試行（spike）**。正式要件（`docs/requirements.json`）は変更しない。scope.out の「字幕」はそのまま。
- 対象 Issue: [#18 字幕表示のON/OFF](https://github.com/Tomonori-Ishii/4x-speed_mp4_player/issues/18)

## 1. 目的

MP4 内蔵の字幕トラック（`tx3g` / mov_text）を JS の MP4 パーサーで切り出し、アプリ側で映像の上に描画できるかを確かめる。

判断に必要な問いは次の 3 点。

1. 既存ライブラリで字幕サンプルを時刻付きで取り出せるか。
2. 再生時刻に合わせて、正しい字幕を正しい時間に出せるか。
3. 描画と ON/OFF が、既存の操作・レイアウト（FR-10 の縦横比、FR-09 の表示幅）と両立するか。

## 2. 方針の決定

| 項目 | 決定 | 理由 |
|---|---|---|
| パーサー | `mp4box`（v2.6.0、BSD-3-Clause、`--save-exact`） | MP4 の box 解析を自作しない。npm audit（本番依存）は 0 件 |
| 字幕の描画 | 自前の DOM オーバーレイ（`<div>` + `textContent`） | `<video>` の内蔵字幕表示に頼らない。二重表示を避ける |
| 字幕の入力元 | ファイル内の tx3g トラックのみ（外部字幕ファイルは対象外） | 試行範囲を絞る。FR-02 の拡張子規則は変えない |
| 読み込み | `File.arrayBuffer()` で全体を読み、字幕だけ別経路で解析 | 再生（Object URL）と字幕の失敗を分離する |
| 字幕がない・解析失敗 | 字幕なしとして再生は続行 | 字幕は付加機能。FR-11 の「再生不能」にはしない |
| 字幕の表示切替 | 映像右上のボタン（既定は ON） | 試行用。最終 UI は別途決める |
| UI の文字 | 「Subtitles: On/Off」（英語） | NFR-10 に合わせる。字幕本文は動画の内容なので英語の対象外 |

## 4. テスト計画

### 4.1 自動テスト（Vitest）

| 対象 | ケース | 期待結果 |
|---|---|---|
| `decodeTx3gSample` | 長さ + UTF-8 の読み取り | 日本語を正しく復元する |
| 同 | 空サンプル、長さ 0、空の入力 | 空文字を返す |
| 同 | 宣言長より後ろに styl などの box がある | 宣言長までの文字だけを返す |
| `normalizeCues` | 空白のみ・長さ 0 のキュー | 除去する |
| 同 | 同一テキストが連続（ローリング字幕） | 1 件に結合し、終了時刻を延ばす |
| 同 | 同一テキストが時間的に離れている | 結合せず別キューにする |
| `cueAt` | 区間内、区間の境界（start は含む、end は含まない）、区間の間・前後・空配列 | 期待どおりのキュー、または null |
| `readTx3gCues`（実ファイル、任意） | `SUBTITLE_SAMPLE` のサンプル | 809 件付近を取得、先頭の開始が 0.28 秒 |
| 既存テスト | 全 54 件 | 回帰なし（確認済み） |

### 4.2 確認済み（この試行で実施）

- `npx tsc --noEmit`：成功
- `npx vitest run`：既存 54 件すべて成功
- `npx vitest run tests/unit/subtitles.test.ts`：8 件成功、実ファイル確認 1 件は環境変数指定時に成功
- Node 上の mp4box で、サンプルの tx3g 809 サンプルを取得（ffmpeg の字幕 808 パケットと概ね一致。先頭の開始 0.28 秒は ffmpeg の SRT と一致）
- `npm run build`：成功（JS バンドルは 443 kB、gzip 124 kB）

### 4.3 未確認（残りの作業で実施）

- Electron 上での字幕の見た目と同期（上記 3 の 1〜3）
- 速度変更・シーク・ループ・ファイル差し替えでの字幕の挙動
- 字幕のない MP4、壊れた MP4（`e2e/fixtures/broken.mp4`）、音声のみ MP4 で、再生が従来どおり動くこと
- 既存の Playwright E2E（28 件）と packaged テスト（2 件）の回帰

### 4.4 E2E を追加する場合の案

- 字幕トラック付きの MP4 を `scripts/make-fixtures.sh` で生成（ffmpeg の `-c:s mov_text`）。`e2e/fixtures/*.mp4` は gitignore 対象のため、リポジトリに含めない。
- 検証項目：再生中に字幕が切り替わる、シーク後に正しい字幕に変わる、OFF で消える、差し替え後に前の字幕が残らない。

## 5. 既知の懸念と対策

| 懸念 | 現状 | 対策案 |
|---|---|---|
| ローリング字幕の重複 | 同一テキストの連続結合で対応 | 表示が不自然なら、行単位の差分表示を検討 |
| `arrayBuffer()` で全体をメモリに読む | 47 MB のサンプルで問題なし | 大きいファイルでは先頭の `moov` 解析と範囲読込に変更 |
| 字幕と映像の時刻ずれ | `elst`（編集リスト）は未対応 | ずれが出たら `elst` を解析 |
| 日本語フォント | CSS で候補を指定 | 環境に無い場合は同梱フォントを検討（ライセンス確認が必要） |
| バンドル増加 | 増分は未計測（現在のバンドルは 443 kB） | 増分を計測し、大きければ字幕を遅延読込（dynamic import）に変更 |
| 壊れたファイルでの例外 | `onError` で reject、呼び出し側で握りつぶす | 2 の決定どおり字幕なしで続行 |
| 字幕の `styl` 等のスタイル | 無視している | 位置・色が必要なら tx3g のスタイル box を解析 |
| 内蔵字幕の二重表示 | `<video>` の内蔵字幕表示は使っていない（未検証の前提） | Electron で確認する |

## 6. 正式化の前に決めること

- scope.out の「字幕」を外すか（要件変更の判断。試行では変更していない）
- 字幕の入力元：内蔵のみか、外部 `.vtt` も含めるか
- 字幕 ON/OFF の既定値と保存（再生位置と同じく保存しない方針か）
- 字幕ボタンの配置（コントロール行に入れるか）
